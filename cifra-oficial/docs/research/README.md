# Conversaciones con usuarios potenciales

Tres conversaciones reales (10–15 min cada una). Una nota por archivo: `entrevista_1.md`, `entrevista_2.md`, `entrevista_3.md`.
Sin datos personales sensibles: usa solo el rol, por ejemplo "periodista económica, medio digital".

## Guía de preguntas

1. ¿Cuándo fue la última vez que necesitaste una cifra oficial (inflación, dólar, pobreza...)? ¿Para qué?
2. ¿Cómo la conseguiste? ¿Cuánto tiempo te tomó? ¿Qué fue lo más molesto?
3. ¿Alguna vez publicaste o casi publicaste un número equivocado? ¿Usas ChatGPT u otro asistente para esto?
4. (Muestra la app 1 minuto.) ¿Lo usarías? ¿Qué le falta? ¿Pagarías por algo así? ¿Cuánto?
